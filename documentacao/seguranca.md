# Segurança e Privacidade

## Natureza dos dados

O SGLE poderá tratar dados pessoais de crianças e adolescentes e informações relacionadas a deficiência e medicação. Portanto, a segurança deve ser considerada desde a primeira versão.

## Repositório GitHub

O repositório deve conter apenas:

- código-fonte;
- documentação;
- modelos sem dados reais;
- exemplos anonimizados ou fictícios.

Nunca publicar dados reais de educandos ou responsáveis.

## Controle de acesso

O acesso à planilha e aos formulários deve ser concedido somente aos profissionais que necessitam das informações para executar suas funções.

## Dados sensíveis

Informações de deficiência e medicação devem ser tratadas como restritas. Dashboards e relatórios gerais devem evitar exposição individual.

## Credenciais

Não armazenar no GitHub:

- senhas;
- tokens;
- chaves de API;
- IDs de serviços privados quando não forem necessários;
- credenciais de contas institucionais.

## Dados de teste

Para desenvolvimento utilizar nomes fictícios e dados sintéticos.

## Princípio de minimização

Coletar somente os dados necessários para a finalidade definida pela instituição e revisar periodicamente se cada campo continua necessário.

## Auditoria futura

Versões posteriores poderão registrar:

- usuário responsável por alterações administrativas;
- data/hora da alteração;
- alteração de status;
- histórico de convocação;
- histórico de matrícula.

## LGPD

A implementação deve ser validada pela instituição quanto à base legal, finalidade, necessidade, retenção, compartilhamento e direitos dos titulares, considerando especialmente o contexto de crianças e adolescentes.
